# TeenageStudyTool — 英文＋國文練習

國中生學習工具：英文單字卡＋測驗＋閱讀練習；國文形音義練習（新）。

## 使用方式
- 英文（v2）：https://yuhsuanyhtu.github.io/TeenageStudyTool/v2/
- 國文（試用版）：https://yuhsuanyhtu.github.io/TeenageStudyTool/chinese/

## 功能
- 單字卡學習（含發音、中文）
- 中翻英拼字測驗（題數可調，最少 6 題）
- 預測遊戲（贏自己預測 +$10）
- 全對獎金 +$100（連續滿分每天減半）
- 連續打卡 5 天獎勵 ×2
- 弱字複習模式
- 獎勵規則透明頁
- 資料匯出 / 匯入備份


## 國文（試用版）
- 選字填空／抓錯字／相似字連連看／詞語配對，全部點選作答
- 計分：第一次答對 ⭐⭐⭐、第二次 ⭐⭐、之後 ⭐（不倒扣）
- 目前收錄 2上 L01〈田園之秋選〉，素材取自翰林備課用書（教學使用）
